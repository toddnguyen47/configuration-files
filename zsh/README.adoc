= zsh config files

Simply run `./install.sh` and you're good to go!

== Add an override to `ZSH_THEME`

To have a possible override, add the following to your `.zshrc`

[source, shell]
----
if [[ -n ${ZSH_THEME_OVERRIDE} ]]; then
    ZSH_THEME="${ZSH_THEME_OVERRIDE}"
else
    ZSH_THEME="random"
fi
----

To use the above code, type these commands into your terminal:

[source, shell]
----
# Use your choice of theme to replace `zx-exit-status`
export ZSH_THEME_OVERRIDE="zx-exit-status"
source ~/.zshrc
----

== Check for RPROMPT and append $ to LPROMPT

Add the below line to `~/.zshrc`

[source, shell]
----
# Add $ to PROMPT
_add_dollar_sign() {
    printf "%s$%s " \
        "%{$fg_bold[yellow]%}" \
        "%{$reset_color%}"
}

# Warn if RPROMPT is set
_rprompt_warning() {
    [[ -n $RPROMPT ]] || return 0
    printf " %s⚠ RPROMPT is set%s" \
        "%{$fg_bold[red]%}" \
        "%{$reset_color%}"
}

PROMPT+='
[$(strftime "%a %Y-%m-%d %H:%M")]$(_rprompt_warning)
$(_add_dollar_sign)'
----

== Plugins

Plugis that I like to use. Add these in `~/.zshrc`

[source, shell]
----
plugins=(
  git
  poetry
  z
  zsh-syntax-highlighting
)
----
